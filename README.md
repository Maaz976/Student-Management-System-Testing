# Student Management System

A full-stack Student Management System built with Node.js, Express, HTML, CSS, and JavaScript.

## Features

- Student management
- User authentication
- Attendance management
- Marks management
- Subject management
- REST API backend
- Simple and responsive frontend

## Tech Stack
## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Authentication:** Express Session
- **Password Security:** bcryptjs
- **Tools:** Git & GitHub
